SpendFlow combines real-time budget tracking with state-of-the-art fintech features.

🔔

Graduated Budget Alerts

Real-time milestone notifications at 25%, 50%, 75%, 90%, and 100%+. Automatically suppresses backlog notifications so you are never spammed.

💱

Live Multi-Currency

Log expenses across NPR (Nepali Rupee), INR (Indian Rupee), USD, EUR, and GBP with real-time exchange rate normalization.

🔒

Biometric App Lock

Protect your financial privacy with seamless Fingerprint / Face ID authentication and automatic timeout locking.

⚡

Instant Offline Sync

Log transactions anywhere without internet. Changes queue securely locally and sync instantly to Supabase cloud once reconnected.

📊

Visual Analytics & Charts

Interactive monthly spending trends, category breakdown donut charts, and spending habit comparisons.

💎

Theme-Adaptive Splash

Luxury Geometric Diamond Matrix splash animation that automatically adapts seamlessly between Light and Dark mode.
